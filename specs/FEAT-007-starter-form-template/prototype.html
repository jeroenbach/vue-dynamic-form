Starter Form Template

Design prototype for @bach.software/vue-dynamic-form-starter. Same visual language as the live Advanced example, rendered through plain sft- CSS classes instead of Tailwind utilities, with Lucide choice-card icons. Toggle light/dark top right.

Buttons Five variants. Maps to AppButton. Icons are Lucide, decorative (aria-hidden).
Hover/focus not demonstrable statically: default darkens its border and background, primary darkens and shows a 2px offset focus ring, danger/danger-light deepen their red wash. Disabled drops to 40% opacity with not-allowed cursor.
Plain text field: validation states Maps to FormField + TextInput. The states policy for every input lives here.
States policy, applied everywhere: pristine = resting gray border, no message. invalid = red/rose border plus an error line below. valid = a filled value with no error; the design signals validity by the absence of an error, there is no green success border. focus adds a 3px sky ring (rose ring when invalid). disabled dims the field to 60% and greys the control. The resting input border is deliberately the same light gray in dark mode (faithful port: the source has no dark variant for it).

Multi-step wizard Maps to FormWizard + Stepper. Done / current / upcoming steps, Back/Continue footer.
