# Archive

Specs that reached `done` and shipped. Each folder is moved here whole, unchanged, from the top level of `specs/` once its work is complete (see "`done` specs move to `specs/archive/`" in `specs/README.md`).

- Nothing here is edited or reopened; new work in the same area links forward from a new spec instead.
- Ids stay reserved: numbering for new specs scans this folder too.
- `deferred` specs do not belong here; they stay at the top level until revived or built.
