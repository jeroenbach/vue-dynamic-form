# Examples

Runnable examples that cover the main features. Each page embeds the live component and highlights the relevant source.

Every example renders through the [starter template](/guide/starter-template), so this section doubles as a showcase of what the starter looks like out of the box. To add your own field types on top of it, see [Extending The Starter Template](/guide/extending-starter) in the guide.

## Features

Each page focuses on one capability of the library, with the smallest form that shows it off.

- [Basic Form](/examples/basic): two fields, a heading group, and form state
- [Arrays & Groups](/examples/arrays-and-groups): repeatable sections with per-item labels
- [Choice Fields](/examples/choices): mutually exclusive branches
- [Wizard](/examples/wizard): multi-step form with per-step validation and a review page
- [Reactive Fields](/examples/reactive-fields): options loaded from an external source
- [Validation](/examples/validation): restrictions, async checks, password strength, and cross-field rules

## Full Examples

Complete, production-style forms that combine the features above into one realistic page.

- [Checkout](/examples/checkout): a complete one-page webshop checkout with a split-payment finale
- [Client Onboarding Wizard](/examples/client-onboarding): a multi-step wizard touching the full feature set
- [Inbox Rules Builder](/examples/inbox-rules): a reorderable, ordered list of rules where order is the whole point
- [Run of Show Builder](/examples/run-of-show): a repeatable ordered choice where reordering changes a computed clock and whether an amplified-music curfew is met
- [Workout Plan Builder](/examples/workout-plan): a repeatable ordered choice where reordering alone satisfies or breaks published coaching conventions
